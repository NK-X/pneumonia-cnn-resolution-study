Figure 7 | Validation ROC-AUC versus total model parameters. The horizontal axis uses a logarithmic scale with parameter counts displayed as plain integers. MobileNetV3-Small contains the same number of parameters at both input resolutions (1,518,881); only the input resolution differs. Its best validation ROC-AUC changed from 0.9900 at 128 × 128 to 0.9938 at 256 × 256 (difference +0.0038). Results use one fixed training seed per configuration; therefore, the observed difference is descriptive rather than an estimate of a general resolution effect. The held-out test set was not evaluated.
